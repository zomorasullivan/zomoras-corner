# A Little Corner — Zamora prototype

A deliberately small React + TypeScript + Vite prototype for Zamora's personal/lifestyle blog concept.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (normally http://localhost:5173).

## Notes

- No database, auth, payments, ads, or hosting dependency.
- Content is currently inline placeholder data so the first prototype stays frictionless.
- The intended next step, if Zamora likes the direction, is to move posts into Markdown/frontmatter files and add a small content loader.
- The name **“a little corner” is only a temporary prototype label**, not a finalized brand decision.
